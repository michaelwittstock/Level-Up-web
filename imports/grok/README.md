# imports/grok

Grok's drop zone for Michael's notes from Grok chats, so they can be moved into Level Up.

**Grok:** write one markdown file per topic, named `YYYY-MM-DD-topic.md` (for example `2026-11-22-workouts.md`). Topics wanted first: workouts, supplements, bloodwork, fasting, food, books, faith, personality.

Each file:

```
# <Topic>
Source: Grok chat "<chat title>" (<date>)

## What Michael decided or said
- ...

## Plans / routines / lists
- ...

## Open questions
- ...
```

Rules: write what Michael actually said or decided; mark your own suggestions as "Grok suggested". No passwords, full card or account numbers, or ID numbers. Write lab values exactly as on the report, including units and the reference range.

**Claude:** turns each file into Notion data (Labs, Supplements, Workout Log, Personal Library and so on), then adds `Imported to Notion <date>` at the top of the file.
